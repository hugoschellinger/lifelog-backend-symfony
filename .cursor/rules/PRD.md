Instructions de Design Global :

Agis en tant que Designer UI/UX Senior spécialisé dans le Web Design minimaliste et moderne. Crée une landing page "One-Page" pour un Développeur Web & Mobile Freelance.
Style : Esthétique "SaaS moderne" (type Linear ou Apple). Fond blanc cassé (#F9FAFB), texte noir profond (#111827). Couleur d'accentuation : Bleu Électrique (#3B82F6) pour les boutons et les points d'intérêt.
Mise en page : Utilise une grille de 12 colonnes, des bordures très fines (1px) et des arrondis de coins (border-radius) de 12px.
Animations : Applique un fade-in-up sur chaque section au scroll et un léger effet de scale (1.05) au survol des cartes.

1. Header (Sticky)

Position : Fixé en haut avec un effet de flou (backdrop-filter: blur).

Contenu : À gauche, un logo textuel en gras "NOM [DEV]". Au centre, navigation : Projets, Expertise, Parcours. À droite, un bouton "Travaillons ensemble" avec un fond coloré.

2. Hero Section (L'accroche)

Mise en page : Centrée verticalement. Titre en extra-bold (H1).

Copywriting : * H1 : "Je bâtis les fondations techniques de votre prochain succès."

Sous-titre : "Développeur Fullstack spécialisé dans la création de MVPs pour startups et la digitalisation de commerces de proximité. Rapide, propre, évolutif."

CTAs : Un bouton principal "Voir mes réalisations" et un bouton secondaire "Réserver un appel diagnostic".

Visuel : Sous les boutons, insère une image abstraite ou une capture d'écran stylisée d'un tableau de bord de code très épuré.

3. Section : À Propos (Le Pont)

Mise en page : Deux colonnes. À gauche, une photo portrait pro et chaleureuse. À droite, le texte.

Copywriting : * Titre : "Plus qu'un développeur, un partenaire technique."

Texte : "Je m'appelle [Prénom]. J'aide les entrepreneurs à transformer une idée floue en un produit tangible. Que vous soyez un commerçant voulant dominer son marché local ou un fondateur de startup pressé de lancer sa version bêta, je m'occupe de l'architecture pour que vous vous concentriez sur la croissance."

4. Section : Projets (La Grille Bento)

Mise en page : Une "Bento Grid" (grille asymétrique moderne).

Contenu (Faux projets) :

Carte 1 (Large) : "NovaSaaS" – Une plateforme de gestion de stock pour commerçants. (React / Node.js).

Carte 2 : "E-Shop Local" – Application mobile de click-and-collect. (Flutter).

Carte 3 : "Landing Page X" – Site vitrine haute performance pour une marque de cosmétique.

Interaction : Chaque carte doit afficher un badge de la techno utilisée au survol.

5. Section : Expérience & Compétences

Mise en page : Liste horizontale de logos d'entreprises (en gris pour la discrétion) suivie d'une section "Stack Technique".

Éléments : 3 colonnes.

Col 1 : "Web" (React, Next.js, Tailwind).

Col 2 : "Mobile" (Flutter, React Native).

Col 3 : "Backend" (Firebase, Supabase, Node).

Détail : Ajoute une petite puce animée "Disponible pour de nouveaux projets" pour rassurer sur la disponibilité.

6. Section : Contact (Conversion)

Mise en page : Un bloc avec un fond légèrement grisé pour se détacher du reste.

Contenu : * Titre : "Prêt à passer à l'étape supérieure ?"

Champs : Nom, Type de projet (Menu déroulant : Startup / Commerce), Budget estimé, Message.

Bouton : "Envoyer ma demande" (Animation : le bouton pulse légèrement).
